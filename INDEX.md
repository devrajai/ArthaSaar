## The repo — `market-data-hub`

The pipeline and the code. Public GitHub repo (not yet pushed). It **produces** data;
it is not the place to read it from a phone.

| Feed | Source | Cadence | Lands in |
|---|---|---|---|
| Bhavcopy (equities + F&O) | NSE, official | daily after close | `data/csv`, `data/parquet`, `data/manifest.csv` |
| Candle archive | grown from bhavcopy | daily | `data/candles/cm_daily.parquet` |
| YouTube uploads (10 channels) | channel Atom feeds | daily | `data/youtube/videos.csv` |
| YouTube analysis ("the brain") | the above | daily | `data/analysis/` |
| F&O analytics | bhavcopy FO | daily | `data/futures.json` |
| Breadth | candle archive | daily | `data/breadth.json` |
| TimesFM forecasts | yfinance + model | nightly | `data/timesfm_forecasts.json` |

Watchdog: `health.yml` checks freshness daily and opens an issue if a feed stalls.

## Google Sheets

| Sheet | What it is | Authoritative? |
|---|---|---|
| **Market Data Hub (Archive)** | the view layer for this repo — Universe, Daily_Snapshot, Fundamentals, Technicals, F_and_O, Index_MF | **yes, for the market hub** |

| IpoBodh IPO Tracker | IPO tracker (with Apps Script) | **yes, for IPOs** |

Rule of thumb: **files in Drive are the archive; the Sheet is the view; the repo is the pipeline.**
Don't put bulk history in a Sheet — 10,000,000 cell limit.

## Known gaps (as of this check)

- **Telegram analytics**: 11 of the 16 JSONs the Telegram jobs read are not producible
  from the hub's own data (smart-brain, mood, gti, oi-gti, radar, events, global,
  fii-dii, mf-top, preopen, brain-screener, index-changes). `futures.json` and
  `breadth.json` are regenerated by `build_analytics.py`; `timesfm_forecasts.json` by
  the forecast job. The rest need the old pipeline or another source.
- **`devrajai/ArthaSaar` is 404** — repo, raw files and the `candles` release tag.
  Anything that pointed there is dead.
- **Candle archive is stale** at 27 Sep 2026; `candles_from_bhavcopy.py --backfill`
  is the way to refresh from NSE.
